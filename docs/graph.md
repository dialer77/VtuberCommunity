# 관계 그래프 (관계도·게임·사건 페이지·검색 바로가기)

흩어진 데이터(버튜버·소속사·키리누키·게임·사건·이슈)의 연결을 한곳에 모은 층입니다. 기존 테이블은 그대로 두고, 서버가 30분마다 메모리에 다시 만듭니다 (`server/src/graph/`). 2026-11-19 추가.

## 점과 선

| 점 | id | 어디서 |
| --- | --- | --- |
| 버튜버 | `v:플랫폼:채널ID` | 수집 채널(최근 180일 활동·키리누키·소속사가 있는 것) + 유튜브 전용 버튜버 |
| 소속사 | `a:태그ID` | 소속사 태그 카탈로그 (명단 기준) |
| 그룹 | `gr:이름` | 유튜브 전용 버튜버의 소속 중 카탈로그에 없는 것 (예: 홀로라이브) |
| 게임·콘텐츠 | `g:이름` | 키리누키 주제 — 클립 3개 이상, "저챗·합방·○○ 잡담" 같은 일반 주제 제외 |
| 사건·밈 | `e:이름` | 키리누키 사건 — 클립 2개 이상 |
| 이슈 | `i:slug` | 이슈 타임라인 |

| 선 | 뜻 | 기준 |
| --- | --- | --- |
| member | 소속 | 소속사 명단·방송 태그, 유튜브 전용 버튜버 소속 |
| collab | 자주 합방 | 키리누키 공동 출연 2번 이상 (숫자 = 함께 나온 클립 수) |
| plays | 이 게임을 함 | 그 게임 클립 2개 이상 |
| event | 사건에 나옴 | 그 사건 클립에 출연 |
| about | 사건의 게임 | 사건 클립의 주제 |
| mentions | 이슈에 등장 | 이슈에 적힌 이름 → 버튜버·소속사 (정확히 같은 이름·괄호 앞부분, 이름이 겹치면 잇지 않음) |

## 화면

| 화면 | 내용 |
| --- | --- |
| 프로필 **관계도** 탭 | 버튜버를 가운데 두고 소속·자주 합방·같은 소속·많이 한 게임·엮인 사건·관련 이슈 (넓은 화면은 마인드맵 그림 + 목록, 좁은 화면은 목록) |
| `/game/<이름>` | 게임·콘텐츠 페이지 — 관계도(한 버튜버·사건·같이 많이 하는 게임) + 클립(좋아요·최신순, 24개씩). 그래프에 없는 이름은 `/clips?q=` 로 |
| `/event/<이름>` | 사건·밈 페이지 — 나온 버튜버·게임 + 클립 |
| `/map?n=<점 id>` | 어떤 점이든 가운데 두고 보는 관계도 (소속사·그룹처럼 따로 페이지가 없는 것) |
| 통합 검색 | 운영자가 이은 검색어 → **바로가기** 카드, 이름이 맞는 게임·사건·소속사 칩 |
| 클립 상세 | "무엇을"의 게임 이름, "어떤 일"의 사건 이름이 각 페이지로 이어짐 |

| `/duo/<A>/<B>` | **합방 조합** — 두 버튜버가 함께 나온 키리누키(좋아요·최신순), 같은 소속, 같이 한 게임·사건(각자 클립 수). 관계도의 '자주 합방' 칩이 여기로 이어짐. A×B·B×A 는 한 주소로 (2026-11-25) |
| `/vtuber/<플랫폼>/<ID>/intro` | **입문 모음 "OO 처음이라면"** — 주인공 클립 중 버모아 좋아요·대표 장면(레전드·명곡·감동 등)·자주 하는 게임을 섞어 10개, 고른 이유 표시, 처음부터 이어서 보기. 같은 게임 2개·같은 순간 3개·같은 키리누키 채널 2개까지. 프로필 키리누키 탭에 입구 (클립 6개 이상) (2026-11-25) |

사이트맵에 클립 3개 이상인 게임·사건 페이지, 함께 나온 클립 5개 이상인 합방 조합, 클립 10개 이상 버튜버의 입문 모음을 넣습니다.

## 주제 이름 통일 (2026-11-25)

같은 게임이 여러 이름으로 갈리면 관계도·게임 페이지에서 따로 보입니다. `server/src/clips/topics.ts` 의 기본 별칭(`SEED_TOPIC_ALIASES`)에 더하면 **서버가 시작할 때 아직 적용하지 않은 것만 기존 클립에도 적용**합니다 (운영자 별칭이 있으면 그대로 둠). 2026-11-25 운영 데이터로 더한 것: 스텔마크·스텔 마크 서버·스텔 마크서버 → 마인크래프트 스텔서버, GTA6·GTA VI·Grand Theft Auto VI → GTA 6, 커버곡 → 노래 커버. "노래 커버·클립 모음·버츄얼 예능·데뷔 방송·신의상 공개" 같은 방송 종류는 일반 주제로 보고 게임 점·비슷한 클립 근거로 쓰지 않습니다. 배포 PC 에서 바로 고칠 때는 `clips.ps1 alias <별칭> <정식 이름>`.

## 관리 (배포 PC)

```powershell
cd D:\01_Project\21_VtuberCommunity
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 status                          # 점·선 개수, 못 이은 이슈 이름 수
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 show "봉누도2"                    # 그 대상의 관계도
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 issues                          # 이슈에 적혔지만 버튜버로 잇지 못한 이름
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 alias-add "리코" "유즈하 리코"     # 검색어(애칭·줄임말·오타) → 대상. 이슈 이름 연결에도 쓰임
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 aliases                         # 이어 둔 검색어
powershell -ExecutionPolicy Bypass -File deploy\windows\graph.ps1 unlink "버튜버A" "버튜버B" collab   # 잘못된 관계 막기 (link 로 더하기, reset 으로 되돌리기)
```

바꾼 내용은 서버가 30분 안에 다시 읽습니다. 이름이 여럿이면 점 id 로 적습니다.

같은 게임이 여러 이름으로 갈려 있으면(예: "마인크래프트 스텔서버"·"스텔마크") 관계도에서도 따로 보입니다. 키리누키 주제 이름 통일(`clips.ps1 alias 스텔마크 "마인크래프트 스텔서버"`)을 하면 다음 그래프부터 합쳐집니다.
