01 한눈에

무엇을 만드는가

치지직·SOOP·유튜브에 흩어져 방송하는 한국 버튜버의 실시간 방송 현황·신규 데뷔·급상승·이슈를 한 곳에 모아 매일 갱신하는 한국어 허브. 정적인 인물 DB가 아니라 "지금 무슨 일이 일어나는가"를 보여줘 반복 방문을 만드는 것이 목표.

포지셔닝 한 줄

국내 인디·신인 버튜버에 특화된, 실시간 방송현황 + 데뷔·급상승·이슈를 자동으로 갱신하는 한국어 실시간 허브. 글로벌·대형은 Holodex/Streams Charts에 양보하고, 그들이 놓친 치지직/SOOP 네이티브 + 이벤트성을 노린다.

가칭 버모아(VMOA) — "버튜버를 모아보다". 대안: 라이브덱 LiveDeck · 뷔넥스트 VNEXT · V-DEX. 개발 코드네임은 Project VDEX 사용.

02 배경

왜 지금, 왜 이 자리인가

유사 서비스는 이미 여럿 있지만 각자 빈틈이 있고, 그 빈틈이 곧 진입 지점이다.

기존 서비스강점빈틈 (= 우리 기회)
Holodex글로벌 라이브·멀티뷰 표준YouTube/Twitch만 — 치지직·SOOP 네이티브 미커버
Streams Charts시청시간 기반 정밀 랭킹유료·영어권 중심, 한국 인디 세분화 약함
소프트콘 뷰어십한국 멀티플랫폼 뷰어십순위 중심, 데뷔·이슈·큐레이션 약함
나의 작은 버튜버중소 버튜버 인물 DB무수익·정체, 실시간성 없음, 알림 종료
브니버스한국판 홀로덱스 시도사실상 정체
벤치마크 — 덥덥미(wwme.kr)

덥덥미는 자동 수집(실시간 폴링) + 크라우드소싱의 하이브리드다. 단, 크라우드소싱은 "실시간 값 입력"이 아니라 "무엇을 추적 대상에 넣을지"를 제보받고 관리자가 검수하는 데 한정된다. 우리는 이 구조를 그대로 채택 — 지표는 100% 자동, 사람은 대상 등록·이슈 큐레이션만 → 운영 부담을 최소화한다.

03 컨셉

3가지 차별점

순위·현황 자체는 레드오션. 차별화는 트래픽이 도는 이벤트성에 둔다. 이 3가지가 곧 AdSense 트래픽 엔진이다.

신규 데뷔 캘린더

오늘·이번 주 데뷔하는 버튜버를 자동 감지·정리. 기존 서비스가 가장 약한 영역.

실시간 급상승

절대 시청자 수가 아니라 변화율 기반 "떡상 감지". 지금 뜨는 방송을 실시간으로.

이슈 타임라인

커뮤니티에 흩어진 사건·이슈를 한 곳에 아카이빙. 자체 텍스트 → AdSense 승인에도 유리.

타깃 사용자

  • 코어 팬 — "내 최애가 지금 방송 중인지, 뭘 하는지" 하루에도 여러 번 확인
  • 신인 발굴형 시청자 — 데뷔·급상승으로 새 버튜버를 찾는 사람
  • 이슈 팔로워 — 씬에서 무슨 일이 있었는지 따라잡고 싶은 사람 (검색 유입 강함)

플랫폼별 확보 난이도와 법적 조건이 크게 다르다. 치지직이 데이터 확보의 중심축이며, Twitch는 한국 철수(2024.2)로 사실상 제외한다.

확보 방식 3단계 분류

🟢 직접 확보

치지직 공식 API(라이브·동접·팔로워·신규감지), YouTube 통계(장기저장 허용), Holodex 무료 API(해외)

🟡 링크만

Streams Charts·소프트콘(데이터 통합은 유료/ND 라이선스), Playboard·vling(API 없음) → 딥링크·출처표기

🟠 회색지대

SOOP·치지직 비공식 엔드포인트. 동작하나 차단 가능 → 공개 통계 한정 + 낮은 폴링 + 캐싱으로 관리

아키텍처를 강제하는 2가지 제약

① 과거 통계는 어느 API도 안 준다. 치지직·SOOP 모두 시계열 미제공 → 1~5분 주기 폴링으로 자체 DB에 시계열을 쌓는 것이 필수 전제.

② YouTube search.list 폴링 금지. 채널 100개만 조회해도 하루 quota(10,000) 소진. 반드시 RSS 피드(무료)로 후보 발견 → videos.list 50개 배치(1 unit)로 확정 조합을 쓴다.

07 감지 로직

신규 데뷔 · 급상승은 어떻게 잡나

신규 데뷔 감지

  • 발견 — 치지직 라이브 목록(/open/v1/lives)을 폴링하며 DB에 없는 channelId 등장 = 신규 후보 등록 (YouTube quota 문제 없음, 가장 쉬운 경로)
  • 판정 — 단일 신호 금지. 개설일 + 과거 이력 부재 + 데뷔 키워드("데뷔/첫방송/初配信/debut") + 구독자·동접 급증을 가중 결합
  • 검수 — 완전 자동보다 커뮤니티 제보 + 사람 검수 혼합 (Holodex·HoloList 공통 패턴)

급상승 감지

  • 원칙: 절대값이 아닌 변화율·속도. 대형 채널 편향 방지
  • 규모 보정 — 동일 팔로워 규모 코호트 내 백분위 순위 (SullyGnome 방식)
  • 기법 — 이동평균 baseline 대비 z-score, 또는 EWMA 이중 창(단기 5분 vs 장기 24시간)
  • 다지표 결합 — 시청자만 X. (동접 + 평균시청자 + 채팅량) 동반 상승으로 판정 (소프트콘 20/40/40 참고)
08 리스크

법적 · 약관 · 운영 리스크

  • YouTube — 원본 30일 저장 한도, 단 통계 수치는 예외로 장기 보관 허용(랭킹 근거). 출처·브랜드 표기 필수
  • Holodex — 무료·출처표기·비경쟁 조건. "홀로덱스 복제 경쟁 서비스"로 보이면 위반 → 한국 특화 자체 가치 필수
  • 소프트콘 — Basic도 CC BY-ND(변형금지) → 가공 집계엔 부적합. 상업 활용은 제휴 문의
  • 비공식 API — 예고 없이 변경·차단 가능. 공개 통계 한정 + 낮은 폴링 + 개인정보/저작물 저장 회피
  • 팬덤 민감성 — "순위 박제"가 갈등을 유발한다는 여론(덥덥미 사례). 버튜버는 더 민감 → vs 구도보다 정보·발견 톤으로 설계
